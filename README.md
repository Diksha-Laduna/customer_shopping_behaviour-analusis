Customer Shopping Behaviour Analysis
Project Overview

This project analyzes customer shopping behaviour to understand purchasing patterns, customer preferences, and shopping trends using SQL and Python.

Objectives
Analyze customer shopping data.
Understand purchasing patterns and customer preferences.
Explore relationships between customer characteristics and shopping behaviour.
Generate insights that can support data-driven business decisions.
